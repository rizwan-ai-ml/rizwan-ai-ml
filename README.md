## 🌐 Socials:
[![LinkedIn](✋ Gesture-Controlled Volume Control System

This project is a Gesture-Controlled Volume Control System built using Python, OpenCV, and MediaPipe.
It allows users to control the system volume without touching the keyboard or mouse, using only hand gestures captured by a webcam.

The distance between fingers is detected in real time and mapped to system volume levels.

📘 Project Overview

With the advancement of Computer Vision and Human–Computer Interaction, gesture-based systems are becoming more popular.
This project demonstrates how hand gestures can be used as an intuitive and touchless interface to control system volume.

The application uses a webcam to track hand landmarks and dynamically adjusts the volume based on finger movement.

🎯 Project Objectives

To build a real-time gesture-based volume controller

To understand hand landmark detection using MediaPipe

To apply Computer Vision concepts using OpenCV

To control system hardware (volume) using Python

To develop a touch-free user interaction system

🧠 Working Principle

Webcam captures real-time video

MediaPipe detects hand and finger landmarks

Distance between thumb and index finger is calculated

This distance is mapped to system volume range

Volume increases or decreases based on finger movement

⚙️ Project Workflow
Step 1️⃣: Install Required Libraries
pip install opencv-python mediapipe numpy pycaw

Step 2️⃣: Capture Webcam Feed

Webcam video is captured using OpenCV

Frames are processed in real time

Step 3️⃣: Hand Detection

MediaPipe detects hand landmarks

Important finger points are identified

Step 4️⃣: Gesture Recognition

Distance between thumb and index finger is calculated

Gesture value is mapped to volume range

Step 5️⃣: Volume Control

Pycaw is used to control system volume

Volume changes dynamically based on hand gesture

Step 6️⃣: Display Output

Live camera feed shown

Hand landmarks displayed

Volume bar shown on screen

🎮 Gesture Controls
Gesture	Action
Fingers Close	Decrease Volume
Fingers Apart	Increase Volume
No Hand Detected	Volume Remains Same
